## 1. 系统总览与数据流

本系统是一套**维保数据采集与统计**系统，围绕"维修记录"这一核心业务数据，自动派生出未过保物料、超比统计、看板等分析结果。

**系统数据流**（各表之间的依赖关系）：

| 数据源 | 流向 | 说明 |
|--------|------|------|
| 开机数量（machine_count） | → 超比统计 | 提供机台数（模板留空时可用） |
| 结算机台数（settlement_machine） | → 超比统计 | 可选：仅手动录入/模板机台数留空时提供机台数 |
| 送货记录（delivery_record） | → 超比统计 | 提供送货数量、每日明细 |
| 156项基础物料表（base_material_156） | → 维修记录 | 回填 156项名称、配件、单价、比例 |
| 156项基础物料表（base_material_156） | → 未过保物料 | 提供配件、维修金额单价 |
| 维修记录（original_record） | → 未过保物料 | 数量≥1 自动下推 |
| 维修记录（original_record） | → 数据看板 | 机台维修金额、故障频次、物料频次 |
| 未过保物料（unwarranted_material） | → 数据看板 | 返修频次 |
| 超比统计（delivery_stats） | → 数据看板 | 超比金额 |

**核心业务逻辑链**：

1. **维修记录**是源头：录入每次维修（日期、厂房、机台号、料号、数量、时间等）。
2. 维修记录**数量 ≥ 1** 时，系统自动**下推一条未过保物料记录**（同事务，保存即生效）。
3. **未过保物料**按"同一厂房+机台号+配件名称"分组，自动计算第几次、总次数、是否超六个月、是否未过保、维修金额。
4. **超比统计**按月汇总：机台数 × 单台机用量 × 比例 = 约定比例数量，与实际上机/返修数据对比得出超比数量与超比金额。
5. **数据看板**从上述各表实时聚合出机台维修金额、故障频次、物料频次、返修频次、返修率。

> ⏰ **定时任务**：系统每天凌晨 03:00（默认，可在系统配置中修改 cron）自动刷新**当前月份**的超比统计数据（送货数量、上机数量、当月返修、每日明细等）。当天录入的数据，次日凌晨会自动补齐；也可在页面上手动触发刷新。

### 1.1 录单顺序与节奏（重要）

系统各模块之间存在**数据依赖关系**：超比统计的"机台数"以**导入模板填写值为准**（模板留空时才从开机数量/结算机台数补充）、"送货数量"来自送货记录、"上机数量/当月返修"来自维修记录。因此**数据源在前、统计在后**，录单顺序错了，当天的超比数据就不完整。

**推荐的录单顺序**：

> ① 开机数量（每月月初 1 次） → ② 送货记录（每天） → ③ 维修记录（每天） → ④ 超比统计（月初导入 1 次 + 日常更新）

| 顺序 | 模块 | 频率 | 时机与方式 |
|------|------|------|-----------|
| ① | **开机数量** | 每月 1 次 | **月初**添加（当月基准线）；仅在超比模板"机台数"留空时作为补充来源（模板已填机台数则可不用） |
| ② | **送货记录** | 每天 | 当日送货录入（Excel 导入或手动） |
| ③ | **维修记录** | 每天 | 当日维修录入（手动/语音/OCR/Excel） |
| ④ | **超比统计** | 每月导入 1 次 + 日常更新 | 月初按管理员模板**导入一次当月数据**（修改模板中各料号对应的"机台数"列与"统计日期/年+月"）；之后的送货数量、上机数量、当月返修等实时数据，点击**"更新当月数据"**按钮刷新即可 |

**统筹一句话**：开机数量月初录一次，送货记录和维修记录每天都录，超比统计月初导入一次模板后日常只需点"更新当月数据"。

> 💡 操作要点：
> - 超比统计的"机台数"以**模板填写值为准**：模板该列留空时，系统会从结算机台数/开机数量查询，查不到补 0；
> - 超比统计的"机台数"列即开机数量的合计，模板中只需维护该列与月份，其余数量列（送货/上机/返修）可留空，由系统从源表统计；
> - 每天录完送货/维修后，建议在超比统计页选择当月并点一次"更新当月数据"，实时核对当日数据是否齐全。

## 2. 通用操作

### 2.1 登录

输入手机号 → 获取短信验证码 → 输入验证码登录。账号由管理员在"用户管理"中创建。登录后**顶部可切换公司**（不同公司的数据相互隔离）。

### 2.2 搜索/筛选

每个列表页顶部有搜索区：关键词模糊搜索（不同模块搜索字段不同），部分模块支持按厂房、未过保状态、日期范围等精确筛选。搜索条件是**叠加**生效的。

### 2.3 排序与分页

- 点击列表表头可排序（升/降序）；
- 分页默认每页 20 条，可切换 50/100 条。

### 2.4 Excel 导入/导出

- **模板下载**：每个模块的导入均先下载系统模板，按模板列填写；
- **导入规则**：按列位置（index）读取，**列顺序必须与模板一致**；料号重复等校验失败的行会跳过并在结果中提示行号与原因；
- **导出**：按当前筛选条件导出全部数据（不受分页限制），导出文件包含汇总行（如超比统计）。

### 2.5 常用操作

- **复制**：要录一条和旧记录差不多的数据，点该行「复制」按钮，改几个字段后提交即可（无需从头填写）；
- **编辑/删除**：列表行内操作；删除维修记录会连带删除它生成的未过保物料（系统会先提示确认）。

## 3. 送货记录

### 3.1 功能定位

登记每天的**送货明细**（日期、物料编码、数量、品牌、新品/维修品、厂房、送货单号等），是超比统计"送货数量、送货免费、每日明细"的数据源。

### 3.2 录入方式

| 方式 | 说明 |
|------|------|
| 手动新增 | 新增 → 填写送货单上的信息 → 提交 |
| 物料自动匹配 | 物料编码输入关键字自动匹配，或点「选择物料」从物料列表一键回填（类别、物料名称、规格型号等） |
| Excel 导入 | 按模板批量导入（列顺序与模板一致） |

### 3.3 关键字段

| 字段 | 说明 |
|------|------|
| 产品属性 | 新品/维修品；**"免费"**属性计入超比统计的"送货免费"数量 |
| 物料序列号 | 维修记录填"上机物料号"时按序列号匹配回填料号 |
| 年+月 | 由送货日期自动生成（`yyyy-MM` 格式，用于超比统计按月匹配） |

### 3.4 自动联动

超比统计按**料号+月份**自动统计本表的送货数量、免费送货数量与每日明细；每日 03:00 定时刷新会重新统计当月数据。送货记录修改/删除后，超比统计点击"更新当月数据"即可获取最新值。

## 4. 维修记录（原始记录）

### 4.1 功能定位

维修记录是系统的**核心数据源**：每次设备维修登记一条记录，系统据此自动回填 156 项信息、计算工时、下推未过保物料、参与看板统计。

### 4.2 录入方式

| 方式 | 说明 |
|------|------|
| 手动新增 | 填写表单保存 |
| 语音输入 | 在"语音输入"框按格式朗读，系统自动解析填充（如：`日期2026年7月21日 班次白班 厂房A 机台号K25 机型FANUC 诊断人张三 维修人李四 … 料号2212673-0461 配件名称丝杆 数量1 …`） |
| OCR 识别 | 上传维修单据图片，自动识别单据内容填充 |
| Excel 导入 | 按模板批量导入 |

### 4.3 料号自动回填（重要）

输入**料号**（或从下拉选择）后，系统自动从 **156项表** 查询并回填：

| 维修记录字段 | 回填来源 |
|-------------|----------|
| **156项名称** | 156项表「156项名称」列 |
| **配件名称** | 156项表「配件」列 |
| 类别/单台机用量/比例/含税单价（在超比统计等场景） | 156项表对应列 |

> ⚠️ 选择料号时回填 156项名称 和 配件名称 两个字段；查不到时保持原值不回填。

### 4.4 上机物料号自动回填

填写"上机物料号"并离开输入框后，系统自动：
1. 从**本月送货记录**中按序列号匹配，回填**料号**（若料号为空）与**配件名称**；
2. 查询本月送货记录匹配数，回填"送货记录引用"。

### 4.5 下机料号

与上机料号相同的 156 项模糊匹配规则，选择后回填；下机料号在未过保物料下推时**优先**作为料号（见 5.6）。

### 4.6 自动计算逻辑

| 计算项 | 规则 | 说明 |
|--------|------|------|
| **年+月** | 由"日期"生成，格式 `FYyyMM`（如 2026-07 → `FY2607`） | 覆盖前端传入值 |
| **厂房+机台号** | 厂房-机台号（两端去空格；任一为空则置空） | 如 `B5-H1` |
| **跨天修正** | 若"结束时间"早于"开始时间"或"报修时间"，**自动加 1 天** | 解决跨天维修（如 23:00 开始、02:00 结束） |
| **维修工时** | 结束时间 − 开始时间（单位：分钟） | 跨天修正后计算 |
| **停机工时** | 结束时间 − 报修时间（单位：分钟） | 跨天修正后计算 |
| **导入时间修复** | Excel 导入时若时间字段年份异常（≤1900），用"日期"列重构日期部分 | 兼容 Excel 1900 纪元问题 |

### 4.7 与未过保物料的联动

- 维修记录**数量 ≥ 1**：保存时自动下推/更新一条未过保物料记录；
- 维修记录**数量 < 1（0 或空）**：删除已关联的未过保物料记录；
- 编辑维修记录：同步更新已下推的未过保物料；
- 删除维修记录：级联删除关联的未过保物料。

> 🔒 一条维修记录只能被一条未过保物料记录关联；未过保物料页"选择维修记录"时不可重复选择。

## 5. 未过保物料

### 5.1 功能定位

未过保物料模块用于跟踪**距上次维修不足 6 个月**的物料维修情况（保修口径内），并计算每次维修的序号、间隔、金额等派生信息。它是"是否过保"判断的核心模块。

### 5.2 数据来源

| 来源 | 说明 |
|------|------|
| 维修记录自动下推 | 维修记录数量 ≥ 1 时自动生成（最常见） |
| 手动新增 | 点击"选择维修记录"回填基础字段，或手工填写 |
| Excel 导入 | 按模板批量导入 |

基础字段回填映射（从维修记录）：处理方式 ← 维修描述、上机物料 ← 上机物料号、配件名称 ← 零件名称、料号 ← 下机料号（无则用上机料号）、日期/厂房/机台号/维修人/数量 ← 对应字段。

### 5.3 ★ 未过保判断逻辑（重点）

系统按**唯一标识编号**（见 5.4）查询该物料上次维修日期，规则如下：

| 条件 | 未过保列的值 |
|------|-------------|
| 上次维修日期存在，且距本次 **< 6 个月** | **未过保** |
| 上次维修日期存在，且距本次 **≥ 6 个月** | （空） |
| 首次维修（无上次记录） | （空） |

**关键点**：
- 判断依据是"同一唯一标识编号的**上次维修日期**"与"本次日期"的**月差**（按自然月计算，不足 6 个月即未过保）；
- 该列由系统**独立重算并覆盖**前端传入/回填值，保证一致性（不再依赖维修记录"是否过保"字段）；
- 无有效分组键（厂房/机台号/配件名称任一为空）或无日期时，无法判断，置空。

> 💡 示例：同一台机 A15 的主轴 2026-01-10 维修过一次，2026-06-20 再次维修 → 两次间隔 5 个月（<6）→ 本次记录"未过保"。若 2026-08-10 第三次维修，距上次（06-20）不足 6 个月 → 仍"未过保"。

### 5.4 ★ 唯一标识编号（分组键）

**唯一标识编号 = 厂房 + "-" + 机台号 + 配件名称**

- 机台号与配件名称之间**无分隔符**（如 `F6-A15主轴`）；
- 配件名称取值优先级：关联维修记录的配件名称（用户口径）＞ 本条记录自身配件名称（156项表"配件"回填或手工填写）；
- 该编号是**第几次/总次数/上次日期/未过保判断**的分组依据。

### 5.5 派生字段计算逻辑

| 字段 | 计算规则 |
|------|----------|
| **类别** | 按料号从物料表回填（查不到保留原值） |
| **配件名称** | 按料号从 156 项表「配件」列回填（已有值不覆盖；查不到保留原值） |
| **年+月** | 由日期生成，格式 `FYyyMM` |
| **本次日期** | = 记录日期 |
| **总次数** | 同一唯一标识编号在库中出现的总次数 + 1（与日期无关；导入时按整组计算） |
| **第几次** | 截至本次日期（含当天）的出现次数 + 1；**不计当前日期之后的记录** |
| **上次日期** | 该编号距离本次最近一次（≤ 本次日期）的出现日期 |
| **上次维修人** | 同上次日期那条记录的维修人 |
| **本次日期+编号** | Excel 序列号 + 唯一标识编号（序列号：1899-12-31 为 0 基准，2026-07-28 → 46231） |
| **上次日期+编号** | 上次日期的 Excel 序列号 + 唯一标识编号（无上次记录为空） |
| **超六个月** | 距上次日期 ≥ 6 个月 → `Y`；< 6 个月 → `N`；**无上次记录 → `1st`** |
| **使用时长/月** | 距上次日期的**整月数**（零头天数舍弃；如 2025-01-20 ~ 2025-03-10 → 1） |
| **维修金额** | 156项表同料号**含税单价 × 数量**（公司内；查不到单价则置空） |

### 5.6 下推料号取值规则

维修记录下推时料号取值为：**下机料号优先**；无下机料号时回退用上机料号；两者都无则空。

### 5.7 总次数实时化

列表页显示的"总次数"为**实时聚合值**：同一唯一标识编号的所有记录显示同一数值，新增/删除记录后刷新即变（不受分页影响）。

### 5.8 表单"重新计算"预览

新增/编辑表单中有"重新计算"按钮，可**预览**所有派生字段（纯读不写库）：第几次、总次数、上次日期、超六个月、使用时长、维修金额等，提交时以系统重算结果为准。

## 6. 超比统计

### 6.1 功能定位

按月统计每个料号的**送货、上机、返修**与**约定比例**的对比，计算**超比数量**与**超比金额**（即超出合同约定比例的部分），是结算对账的核心模块。

### 6.2 录入方式

手动新增（料号/系统名称自动匹配回填）、Excel 导入（含每日明细列）。

### 6.3 自动回填（只读字段）

输入料号（或系统名称）选中后，自动查询回填：

| 字段 | 来源 |
|------|------|
| 类别、系统名称、配件名称、单台机用量、比例、含税单价 | 156项表 |
| **机台数** | 模板导入值优先；模板留空时从结算机台数表按料号+月份汇总（SUM，查不到补 0） |
| **送货数量** | 送货记录表当月同料号记录数 |
| **免费送货数量** | 送货记录表当月同料号且产品属性为"免费"的记录数 |
| **上机数量** | 原始记录表当月同料号记录数 |
| **当月返修** | 未过保物料表当月同料号记录数 |
| **每日明细** | 当月每一天的送货数量 |

> ⚠️ 自动查询字段（送货数量、上机数量、当月返修、每日明细）为**只读**，不可手动修改。如需修正，请在源表中调整后等待定时刷新或重新打开表单。

### 6.4 ★ 超比计算逻辑（重点）

**第一步：比例 → 小数**。比例只允许在数据入口转换一次：Excel 导入时若比例 > 1 则 ÷100（如 15 → 0.15）；手动录入由前端提交时 ÷100。系统重算方法**不再**转换（保证幂等，避免 100 倍错误）。

**第二步：派生字段统一计算**（新增/编辑/导入/定时刷新同一口径）：

| 计算项 | 公式 |
|--------|------|
| **年月** | 由统计日期生成，格式 `yyyy-MM`（如 2026-07-28 → `2026-07`） |
| **约定比例数量** | 单台机用量 × 比例 × 机台数（保留 2 位小数，四舍五入） |
| **超比数量** | max(0, 上机数量 − 当月返修 − 约定比例数量) |
| **超比含税金额** | 含税单价 × 超比数量 ÷ 1.13（保留 2 位小数） |

> 💡 通俗理解：**约定比例数量** = 该料号按合同比例应有的用量；**超比数量** = 实际装上机的数量 − 返修数量 − 约定数量，**只为正数**（负数按 0，即不欠比例）；超比金额按含税单价算出后**除以 1.13 去税**。
>
> 📝 示例：某料号单台机用量 1.5、比例 15%（0.15）、机台数 10 → 约定比例数量 = 1.5×0.15×10 = 2.25。当月上机 8、返修 1 → 超比数量 = 8−1−2.25 = 4.75。含税单价 120 → 超比含税金额 = 120×4.75÷1.13 = 504.42。

### 6.5 汇总行（全部数据，单位：万元）

表格上方显示全表汇总（不受分页限制，受筛选条件影响）：

| 汇总项 | 公式 |
|--------|------|
| 送货金额合计 | Σ(含税单价 × 送货数量) ÷ 1.13 ÷ 10000 |
| 上机金额合计 | Σ(含税单价 × 上机数量) ÷ 1.13 ÷ 10000 |
| 返修金额合计 | Σ(含税单价 × 当月返修) ÷ 1.13 ÷ 10000 |
| 比例内金额合计 | Σ(含税单价 × 约定比例数量) ÷ 1.13 ÷ 10000 |
| 超比金额合计 | Σ(含税单价 × 超比数量) ÷ 1.13 ÷ 10000 |
| 超比含税总额 | Σ(超比含税金额) ÷ 10000 |

> 📐 逻辑：每行含税单价 × 对应数量，**先求和再** ÷1.13（去税）÷10000（换算万元）。超比含税总额与其他项不同：直接用每行已去税的"超比含税金额"求和 ÷10000（不再重复去税）。

### 6.6 每日明细

每条统计记录展示当月 1 日至月末最后一天的**送货数量**明细（按所选统计日期动态确定天数）。导入时可一次性填入；定时刷新会按送货记录重新生成。

### 6.7 定时刷新

- 默认每天 **03:00** 执行（cron 可在系统配置 `scheduler.cron` 修改）；
- 只刷新**当前月份**的超比统计记录：重新计算送货数量、免费送货、上机数量、当月返修、每日明细，并统一走 5.4 的派生计算；

## 8. 开机数量

### 8.1 功能定位

登记各料号每月的开机数量，**占比**自动计算（以基准线为 100%）。

> 💡 **月初快捷方式**：如果当月开机数量与上个月**一模一样**，只需先将上个月数据**导出**，再修改"月份"后**导入**即可，无需逐条重新录入。

### 8.2 ★ 占比计算逻辑

- **基准线**：占比为 100% 的记录。同一个月（公司内）**只允许一条基准线**；
- **非基准线占比** = 本记录数量 ÷ 当月基准线数量 × 100（保留 2 位小数）；
- **当月无基准线**时，第一条记录自动成为基准线（占比 100%）；
- **设置新基准线**：把某条记录的占比改为 100% 保存时，旧基准线按新基准线**重新计算占比**（旧数量 ÷ 新数量 × 100），保持同月占比总和的一致性；
- 删除/编辑基准线会触发当月所有记录占比重算。

> 💡 示例：3 月基准线为 A 料号 100 台（100%）。B 料号 50 台 → 占比 50/100×100 = 50%。若把 B 改为基准线（100%），A 重算为 100/50×100 = 200%（按新基准重算旧基准）。

## 11. 数据看板

### 11.1 看板类型

| 看板 | 行维度 | 数据源 | 计算口径 |
|------|--------|--------|----------|
| **机台维修金额** | 厂房-机台号（去重） | 维修记录 | 按月 SUM 维修金额；列 = 12 月 + 小计 |
| **机台故障频次** | 厂房-机台号（去重） | 维修记录 | 按月 COUNT；列 = 12 月 + 小计 |
| **物料频次** | 156项料号 | 维修记录 | 按月 COUNT；列 = 12 月 + 合计 + 金额（单价×合计） |
| **返修频次** | 156项料号 | 未过保物料 | 按月 COUNT **非首次维修**（有上次日期）的记录；列 = 12 月 + 合计 + 金额 |
| **返修率** | 156项料号 | 物料频次 ÷ 返修频次 | 按月：返修频次 ÷ 物料频次（4 位小数）；分子或分母为 0 → 空白 |

### 11.2 关键口径

- **月份列**格式 `FY2601`~`FY2612`；
- **返修频次**以"非首次维修（上次日期非空）"近似判别（用户确认口径，覆盖 Excel 原表返修标记 96.7%）；
- **返修率**：分子为 0 或分母为 0 → 显示空白（不显示 0%，与 Excel 原表会计格式一致）；平均列 = 合计返修 ÷ 合计物料，合计返修 0 → 空白；
- **汇总行**：各月列求和；料号类看板有金额列（单价 × 合计），汇总金额 = Σ(各行金额)；
- 看板数据 **60 秒缓存**：更新源数据后最多 60 秒刷新；
- 机台键缺失（厂房或机台号为空）不构成看板行。

## 12. 常见问题（计算口径 FAQ）

**Q1：为什么这条维修记录"未过保"列是空的？**
A：两种情况：(1) 距上次维修 ≥ 6 个月或首次维修（无上次记录）；(2) 无有效分组键（厂房/机台号/配件名称任一为空）或日期为空，系统无法判断。判断规则见 5.3。

**Q2："未过保"和"超六个月"是什么关系？**
A：两者都按"距上次维修的月数"判断，但口径不同：**未过保** = 月差 < 6（且非首次）；**超六个月** = 月差 ≥ 6 → `Y`，< 6 → `N`，无上次记录 → `1st`。首次维修（无上次记录）时：未过保为空、超六个月为 `1st`。

**Q3：超比数量为什么会是 0？**
A：超比数量 = max(0, 上机 − 返修 − 约定比例数量)。当实际上机量未超过约定比例（含返修扣除）时为 0，即不欠比例，不产生超比金额。

**Q4：超比统计的送货数量/当月返修不更新？**
A：这些字段为只读自动查询值，来自送货记录/维修记录/未过保物料源表。当天新录数据需等待次日凌晨定时刷新（或重新打开表单触发重新查询）。注意定时刷新只处理**当前月份**。

**Q5：维修金额怎么算的？**
A：156项表同料号**含税单价 × 数量**（公司内），查不到单价则置空。

**Q6：为什么导入的 156 项比例变成小数了？**
A：导入时比例 > 1 自动 ÷100（如 15 → 0.15），这是系统唯一一次的转换点，重算不再转换——请用模板原始数值导入，不要自己先除一次。

**Q7：看板的返修频次与维修记录对不上？**
A：返修频次以"非首次维修（上次日期非空）"近似统计，首次维修不计数；且看板有 60 秒缓存，源数据更新后稍等刷新。

**Q8：未过保物料"总次数"为什么变了？**
A：总次数是**实时聚合值**（同一唯一标识编号所有记录的总数），新增/删除同编号记录后刷新即变，不是落库快照。

**Q9：维修记录删除后未过保物料会怎样？**
A：级联删除其关联的未过保物料记录；编辑维修记录则同步更新关联记录（基础字段重新回填 + 派生字段重新计算）。

**Q10：同一天同一料号多次维修，第几次怎么排？**
A：第几次 = 截至当天（含当天）的出现次数 + 1，按记录顺序追加编号；导入时按 Excel 行序作为业务顺序。

**Q11：未过保物料里的数据无法修改怎么办？**
A：未过保物料由维修记录自动下推生成，派生字段由系统统一重算，**不支持直接改**。修改对应的**维修记录**数据，关联的未过保物料会自动同步更新；删除维修记录会连带删除对应未过保物料（系统先提示确认）。

**Q12：输入料号后没有带出数据？**
A：按以下顺序排查：① 156项表里有没有这个料号（料号+公司内唯一）；② 超比统计等场景是否**选择了统计日期/月份**（按月匹配）；③ 当月有没有对应的送货/维修/未过保数据（数据源为空则无可回填）。
